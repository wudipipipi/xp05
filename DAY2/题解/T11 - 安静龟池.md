# 安静龟池

## 题目大意

给定一个 $N\times M$ 的网格，其中 $1$ 表示水域格子，$0$ 表示有设备的格子。

现在要在一些水域格子中放小乌龟，要求：

- 至少放一只；
- 只能放在水域格子中；
- 任意两只小乌龟不能上下左右相邻。

求可行方案数，答案对 $10^9+7$ 取模。

## 思路分析

因为 $M\le 10$，列数很小，所以可以考虑按行做状态压缩 DP。

对于一行来说，我们用一个二进制数 $s$ 表示这一行哪些位置放了小乌龟。如果第 $j$ 位是 $1$，表示这一行第 $j$ 列放了一只小乌龟。

首先，同一行内不能左右相邻，所以一个状态 $s$ 必须满足：

$$
(s \& (s<<1))=0
$$

也就是不存在两个相邻的 $1$。

接下来还要考虑设备格子。把第 $i$ 行的水域情况也压成一个二进制数 $water_i$，如果某一位是 $1$，表示这一格是水域。

那么状态 $s$ 能放在第 $i$ 行，当且仅当：

$$
(s \& \sim water_i)=0
$$

也就是 $s$ 中所有为 $1$ 的位置，都必须是水域。

最后考虑上下相邻。假设上一行状态是 $pre$，当前行状态是 $s$，如果同一列都放了小乌龟，就会上下相邻，所以需要满足：

$$
(pre \& s)=0
$$

于是可以设：

$$
dp[i][s]
$$

表示处理完前 $i$ 行，并且第 $i$ 行状态为 $s$ 的方案数。

转移时枚举上一行状态 $pre$：

```c++
if ((pre & s) == 0) {
    dp[i][s] += dp[i - 1][pre];
}
```

其中 $s$ 必须是第 $i$ 行可以使用的合法状态。

为了方便处理“不放任何小乌龟”的情况，我们可以让 DP 中包含全空方案，最后答案减去 $1$ 即可。

下面是正解：

```c++
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<int> water(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < m; j++) {
            int x;
            cin >> x;
            if (x == 1) {
                water[i] |= (1 << j);
            }
        }
    }

    int max_state = 1 << m;
    vector<int> states;

    for (int s = 0; s < max_state; s++) {
        if ((s & (s << 1)) == 0) {
            states.push_back(s);
        }
    }

    vector<int> dp(max_state, 0), ndp(max_state, 0);
    dp[0] = 1;

    for (int i = 1; i <= n; i++) {
        fill(ndp.begin(), ndp.end(), 0);

        for (int s : states) {
            if ((s & ~water[i]) != 0) {
                continue;
            }

            for (int pre : states) {
                if ((pre & s) != 0) {
                    continue;
                }

                ndp[s] += dp[pre];
                if (ndp[s] >= MOD) {
                    ndp[s] -= MOD;
                }
            }
        }

        dp.swap(ndp);
    }

    int ans = 0;
    for (int s : states) {
        ans += dp[s];
        if (ans >= MOD) {
            ans -= MOD;
        }
    }

    ans = (ans - 1 + MOD) % MOD;
    cout << ans << '\n';

    return 0;
}
```

合法状态个数记为 $S$。因为 $M\le 10$，所以 $S$ 很小，最多只有一百多个。

每一行枚举当前状态和上一行状态，时间复杂度为：

$$
O(NS^2)
$$

空间复杂度为 $O(2^M)$。
