# 最后一包馍片 submission matrix

## Method

- Compile command: `g++ -std=c++17 -O2 code_models/<program>.cpp`.
- Run each program on every `data/NN.in`; compare normalized stdout with `data/NN.out`.
- Per-test timeout: `5s`.
- Status: AC means exact normalized output match; WA mismatch; TLE timeout; RE nonzero exit; CE compile error.
