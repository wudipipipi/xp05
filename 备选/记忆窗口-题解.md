# 记忆窗口 题解

## 各部分分做法

### 子任务 1：$q\le200$

直接用数组保存当前窗口中的所有消息。

加入新消息后，如果需要维护，就每次线性扫描所有仍在窗口中的消息，找出尚未压缩且 $(r,id)$ 最小的一条进行压缩。

若所有消息都压缩过仍然超限，就从数组最前面开始删除仍在窗口中的消息。

复杂度 $O(q^2)$。

### 子任务 2：特殊性质 A

不会触发维护。

只需要用哈希表记录每个 $id$ 对应的 token 数，并维护当前数量 `cnt` 和总和 `S`。`ADD` 时直接加入，`ASK` 和 `STAT` 按定义输出即可。

复杂度 $O(q)$。

### 子任务 3：特殊性质 B

所有 $r$ 相同，且 $id$ 按加入顺序递增。

此时待压缩消息中 $(r,id)$ 最小的一条，就是最早加入且尚未压缩的消息。因此可以用一个队列维护尚未压缩的消息顺序。

同时再用一个队列维护当前窗口的进入顺序，用于删除最早消息。

每条消息最多进入、弹出队列一次，复杂度 $O(q)$。

### 子任务 4：特殊性质 C

保证不会删除消息，只会发生压缩。

维护一个有序集合，集合中存放所有尚未压缩且仍在窗口中的消息，关键字为 $(r,id)$。

每次需要压缩时，取集合最小元素，执行

$$
t\leftarrow \left\lceil\frac{t}{2}\right\rceil,
$$

同步修改总和 $S$，再把这条消息从集合中删除。

由于没有删除操作，不需要维护进入顺序队列。复杂度 $O(q\log q)$。

### 子任务 5：特殊性质 D

重要性等级只有 $1$ 到 $30$。

可以为每个等级维护一个集合，集合中存放该等级下尚未压缩消息的 $id$。每次找待压缩消息时，从等级 $1$ 到 $30$ 扫描第一个非空集合，再取其中最小的 $id$。

删除最早消息仍然用进入顺序队列维护。

因为每次寻找最多扫描 $30$ 个等级，每条消息最多被压缩一次、删除一次，所以复杂度为 $O(30q\log q)$。

## 满分做法

维护三类信息：

- `mp[id]`：记录消息是否仍在窗口中、当前 token 数、重要性等级、是否已压缩；
- `ord`：按进入顺序保存消息编号，用于删除最早消息；
- `set`：保存所有尚未压缩且仍在窗口中的消息，关键字为 $(r,id)$。

同时维护当前窗口消息数 `cnt` 和 token 总和 `S`。

### 加入消息

执行 `ADD id t r` 时：

1. 把消息加入 `mp`；
2. 将 $id$ 放入进入顺序队列 `ord`；
3. 将 $(r,id)$ 放入有序集合；
4. 更新 `cnt` 和 `S`；
5. 调用维护过程。

### 压缩阶段

当 $S>W$ 且有序集合非空时，取集合中的最小元素 $(r,id)$。

设这条消息当前 token 数为 $x$，压缩后的值为

$$
y=\left\lceil\frac{x}{2}\right\rceil=\frac{x+1}{2}.
$$

于是

$$
S\leftarrow S-(x-y).
$$

然后更新该消息的 token 数，标记为已压缩，并从有序集合中删除。

即使 $x=1$，压缩后 token 数仍为 $1$，也要标记为已压缩，避免之后再次选择它。

### 删除阶段

如果有序集合已经为空但 $S>W$，说明当前窗口内所有消息都压缩过了。

此时不断从进入顺序队列 `ord` 的队首取消息编号。若这条消息已经不在窗口中，就跳过；否则删除它：

- `cnt` 减一；
- `S` 减去它当前的 token 数；
- 标记这条消息不在窗口中。

直到 $S\le W$。

### 查询

对于 `ASK id`：

- 若 `mp` 中存在该编号，且它仍在窗口中，输出当前 token 数；
- 否则输出 $-1$。

对于 `STAT`，输出 `cnt S`。

## 正确性说明

有序集合始终保存所有“当前仍在窗口中且尚未压缩”的消息，并按 $(r,id)$ 排序。因此压缩阶段每次取出的消息，正好满足题目要求的最小重要性等级和最小编号。

每次压缩后，这条消息被标记为已压缩并从集合中删除，所以任何消息最多被压缩一次。

当集合为空时，说明当前窗口中不存在尚未压缩的消息。如果此时仍有 $S>W$，题目要求删除最早进入窗口的消息。队列 `ord` 恰好按进入顺序保存消息编号，跳过已经删除的旧编号后，队首仍在窗口中的消息就是应该删除的消息。

因此维护过程中的每一步都与题意一致，查询输出也与当前窗口状态一致。

## 复杂度

每条消息最多：

- 插入有序集合一次；
- 从有序集合删除一次；
- 从进入顺序队列弹出一次。

所以总复杂度为

$$
O(q\log q),
$$

空间复杂度为 $O(q)$。
