# 环形试炼

输入文件：hero.in

输出文件：hero.out

## 题目描述

小码君正在参加一场环形试炼。

试炼中有 $n$ 个关卡，编号为 $1 \sim n$。小码君初始时的能力值为 $x$。若要通过第 $i$ 个关卡，需要当前能力值满足 $x \geq a_i$。通过第 $i$ 个关卡后，小码君的能力值会增加 $b_i$。

小码君会按照如下策略挑战关卡：

1. 选择一个整数 $j$，满足 $1 \leq j \leq n$，然后按 $j,j+1,\dots,n$ 的顺序挑战关卡；
2. 如果 $j \geq 2$，再回头按 $1,2,\dots,j-1$ 的顺序挑战关卡。

在能够按照上述策略通过所有关卡的前提下，请求出小码君初始能力值 $x$ 的最小值。

## 输入格式

输入的第一行包含一个整数 $n$。

输入的第二行包含 $n$ 个整数 $a_1,a_2,\dots,a_n$。

输入的第三行包含 $n$ 个整数 $b_1,b_2,\dots,b_n$。

## 输出格式

输出一行一个整数，表示小码君初始能力值 $x$ 的最小值。

## 样例

### 样例 1 输入

```text
5
1 3 2 8 6
4 3 1 1 2
```

### 样例 1 输出

```text
1
```

### 样例 2 输入


### 样例 2 输出

```text
3
```

### 样例 3 输入

### 样例 3 输出

```text
9
```

### 样例 4 输入


```text
0
```

## 提示

### 【样例 1 解释】

令 $x=1$，选择 $j=1$，然后按照 $1,2,\dots,5$ 的顺序挑战关卡，可以通过所有关卡。

该样例满足子任务 $1,2,3,5$ 的限制。

### 【样例 2 解释】

令 $x=3$，选择 $j=3$，然后先挑战第 $3,4,5$ 个关卡，再挑战第 $1,2$ 个关卡，可以通过所有关卡。

该样例满足子任务 $1,2,3,5$ 的限制。

### 【样例 3 解释】

该样例满足所有子任务的限制。

### 【样例 4 解释】

该样例满足子任务 $1,2,3,5$ 的限制。

### 【数据范围】

本题采用测试点捆绑，同一行中的测试点作为一个测试点组计分。

对于所有测试数据，保证：

- $2 \leq n \leq 5 \times 10^5$；
- $0 \leq a_i \leq 10^9$；
- $0 \leq b_i \leq 10^9$；
- 输入的所有数均为整数。

| 子任务 | 分值 | $n$ | 特殊性质 |
| :--: | :--: | :--: | :--: |
| $1 \sim 5$ | $10$ | $2000$ | A |
| $6 \sim 15$ | $20$ | $2000$ | 无 |
| $16 \sim 25$ | $20$ | $5 \times 10^5$ | A |
| $26 \sim 35$ | $20$ | $5 \times 10^5$ | B |
| $36 \sim 50$ | $30$ | $5 \times 10^5$ | 无 |

特殊性质 A：保证答案不大于 $10$。

特殊性质 B：对于所有 $1 \leq i \leq n$，均有 $b_i=1$。
