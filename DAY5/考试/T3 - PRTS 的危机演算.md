# PRTS 的危机演算

## 题目背景

罗德岛的 PRTS 系统每天都会为干员们生成大量虚拟作战环境。最近，博士决定开展一项代号为“极值测试”的特殊战术推演，用来模拟战场上的各种极端情况。

## 题目描述

博士在控制终端上输入了两个整数序列 $A$ 和 $B$。其中序列 $A$ 包含 $n$ 个参数，序列 $B$ 包含 $m$ 个参数。这些参数可能为正数、负数或零。

接着，PRTS 利用这两个序列交叉运算，生成一个大小为 $n \times m$ 的矩阵 $C$。矩阵 $C$ 中第 $i$ 行第 $j$ 列的值定义为：

$$
C_{i,j}=A_i \times B_j
$$

若将矩阵 $C$ 中的 $n \times m$ 个数按照不降序排列，博士希望知道其中排名第 $K$ 的数是多少。

请你帮助博士求出这个数。

## 输入格式

第一行包含三个整数 $n,m,K$，分别表示序列 $A$ 的长度、序列 $B$ 的长度以及询问的排名。

第二行包含 $n$ 个整数 $A_1,A_2,\ldots,A_n$。

第三行包含 $m$ 个整数 $B_1,B_2,\ldots,B_m$。

## 输出格式

输出一行一个整数，表示矩阵 $C$ 中所有数按不降序排列后的第 $K$ 个数。

## 样例

### 样例 1 输入

```text
3 3 5
1 2 3
1 2 3
```

### 样例 1 输出

```text
3
```

### 样例 2 输入

```text
2 3 4
-1 2
1 -2 3
```

### 样例 2 输出

```text
2
```

## 提示

### 【样例 1 解释】

矩阵 $C$ 中的 $9$ 个数为：

$$
1,2,3,2,4,6,3,6,9
$$

将它们按不降序排列后为：

$$
1,2,2,3,3,4,6,6,9
$$

其中第 $5$ 个数为 $3$。

### 【样例 2 解释】

矩阵 $C$ 中的 $6$ 个数为：

$$
-1,2,-3,2,-4,6
$$

将它们按不降序排列后为：

$$
-4,-3,-1,2,2,6
$$

其中第 $4$ 个数为 $2$。

### 【数据范围】

本题采用测试点捆绑，同一行中的测试点作为一个测试点组计分。

对于所有测试数据，保证：

- $1 \leq n,m \leq 5 \times 10^5$；
- $-10^9 \leq A_i,B_j \leq 10^9$；
- $1 \leq K \leq n \times m$。

| 子任务 | 分值 | $n,m$ | 特殊性质 |
| :--: | :--: | :--: | :--: |
| $1 \sim 3$ | $15$ | $1000$ | 无 |
| $4 \sim 5$ | $10$ | $5 \times 10^5$ | A |
| $6 \sim 8$ | $15$ | $5 \times 10^5$ | B |
| $9 \sim 14$ | $30$ | $5 \times 10^5$ | C |
| $15 \sim 20$ | $30$ | $5 \times 10^5$ | 无 |

特殊性质 A：保证 $K=1$ 或 $K=n \times m$。

特殊性质 B：对于所有 $1 \leq i \leq n$，均有 $A_i=i$；对于所有 $1 \leq j \leq m$，均有 $B_j=j$。

特殊性质 C：保证对于所有 $1 \leq i \leq n$，$A_i>0$；对于所有 $1 \leq j \leq m$，$B_j>0$。

危机评级的绝对值可能超过 $32$ 位有符号整数能够表示的范围，请使用合适的整数类型。
