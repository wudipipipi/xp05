# 老城糕色代码模型

| 文件 | 算法/假设 | 预期用途 |
| :-- | :-- | :-- |
| `correct.cpp` | 二分答案 + 贪心最远覆盖 | 满分基准 |
| `subtask1_bruteforce.cpp` | `n<=18` 枚举购买集合 | 测试点 1~2 |
| `subtask2_m1.cpp` | `m=1` 单点公式 | 测试点 3~4 |
| `subtask3_buy_all_unique.cpp` | 可买全部不同色泽 | 测试点 5~7 |
| `subtask4_small_k.cpp` | `k<=5000` 值域覆盖 | 测试点 8~11 |
| `subtask5_m2.cpp` | `n<=5000,m=2` 枚举双点 | 测试点 12~15 |
| `subtask6_n500_full.cpp` | `n<=500` 使用满分判定 | 测试点 16~19 |
